# ADR-0004: License

- **Status:** Accepted
- **Date:** 2026-11-07

## Decision
MIT License for code. Options considered: Apache-2.0 (patent grant, longer), AGPL-3.0 (strong copyleft, discourages reuse).

## Consequences
Code is freely reusable. Odds and stats data are governed by provider terms and are not covered by the license.
